Measurement roadmap

Know the limits.

Screen funnels, crashes, client-side save retries, and cohort retention are not instrumented here yet. These require dedicated app events and privacy review.

Account-level API presence is retained for 30 days; route aggregates for 90 days when scheduled cleanup runs. The dashboard never displays names, email addresses, meal contents, health measurements, posts, or request payloads. Product totals reflect current records, not immutable historical events.
